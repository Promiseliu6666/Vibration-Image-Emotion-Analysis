Wi-Fi / 局域网设备接入

先登记真实 MAC，再将地址与专属密钥配置到设备端。登记成功后，还需收到真实图像并完成分析。

怎样完成真实 Wi-Fi 接入？

先在系统设置更改管理员密码，启用局域网并重启。服务器与设备需处在可互通的网络，服务器防火墙允许 TCP 8000。

支持自定义视觉服务的小智固件：将 vision_url 和 device_key 设置为视觉地址与 Bearer 密钥，触发摄像头拍照即可上传并返回当前状态。此方式按拍照请求分析，不能视为持续采集。

持续采集固件或网关：向 frame_url 上传 JPEG，携带 Authorization: Bearer 密钥；每 20 秒调用 heartbeat_url。现有 USB 连续采集仍可使用。

仅连接 Wi-Fi 不会自动产生图像。当前设备的自定义视觉配置和独立持续采集，需要针对它安装的固件完成实机适配。
