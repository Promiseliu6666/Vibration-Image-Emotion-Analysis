# 摄像头算法与监测面板

目标：保留疲劳检测原始画面和默认隐藏线框；为统一摄像头目录增加应用场景和算法配置，并按配置切换现有指标面板。

实现选择：复用现有幸福指数、疲劳检测面板，由监测入口按摄像头配置挂载其中一个；相比重写指标卡片，可保留现有指标解释和请求清理逻辑。每个摄像头选择一个主分析算法，辅助人脸检测、稳定检测与身份识别在目录说明其依赖关系。现有外部算法目录保留。

配置保存在服务端 `.runtime/camera-algorithms.json`，原子写入，跨浏览器共享，默认幸福指数，线框默认隐藏。配置只绑定已有摄像头编号，不改变现有采集与模型服务。
