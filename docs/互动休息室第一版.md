# 互动休息室第一版

入口：http://127.0.0.1:5173/xiaozhi/rest

沿用原系统登录。侧边栏只在“小智监测”下增加“互动休息室”，原有项目、菜单和登录入口保留。

## 使用

1. 如服务未运行，双击桌面项目外层的“启动互动休息室.cmd”。它只启动本功能需要的原主系统数据库、缓存、后端和前端，保留既有服务与配置。
2. 进入“小智监测 → 互动休息室”，选择呼吸放松（60秒）、远眺休息（60秒）或肩颈放松（90秒）。
3. 可以直接点击“开始休息”。如需手势，先选择本机、RTSP或具体小智摄像头，再点击“开启手势识别”。小智需原服务与设备采集在线，不会回退到本机摄像头。
4. 手心朝向镜头、五指展开并保持约1秒，开始所选项目。进行中可暂停、继续或提前结束。
5. 服务端计满后，竖起大拇指并保持约1秒，或点击“确认完成，保存记录”。提前点赞不会完成计时，也不会锁住结束后的确认。
6. 完成卡片会保存到当前登录账号，刷新仍保留；提前结束不计入已完成记录。

语音开关明确标为“浏览器语音”。现有小智固件仅提供固定提醒音，本版不宣称自定义引导已从小智扬声器播放。浏览器不支持语音时，页面提示和按钮仍可使用。

## 实现与数据

- 路由：/xiaozhi/rest。
- 后端：module_interaction/rest_service.py 和 rest_controller.py，接口前缀 /interaction/rest。
- 使用原登录认证，按登录 user_id 隔离记录。
- 记录保存在后端 .runtime/interactive-rest.sqlite3，不改原数据库结构。
- 服务端计时、暂停不累计、完成幂等；刷新和切页不会重建已存在会话。
- 原始帧复用已有 CameraHub；页面不保存摄像头图像。退出或关闭手势会取消请求、释放模型。
- MediaPipe Gesture Recognizer 以CPU在浏览器内运行。SDK、WASM和8.37MB模型均放本地，运行时无需CDN，不上传画面做识别。
- 采用0.60分类阈值，至少3个不同帧、持续约1秒才触发；有2.5秒冷却及释放锁。JPEG内容指纹用于过滤重复画面。

模型来源：[Google MediaPipe Gesture Recognizer](https://ai.google.dev/edge/mediapipe/solutions/vision/gesture_recognizer/web_js)。下载地址和 SHA-256 记录在 public/gesture-assets/MODEL-SOURCE.json。SDK版本锁定 @mediapipe/tasks-vision 0.10.32；SDK/WASM遵循其上游许可证。
