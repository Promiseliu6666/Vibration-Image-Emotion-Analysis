# 智能视频分析平台快速开始

1.日常启动使用统一的 `start-local.cmd`

2.浏览器访问：

```text
http://localhost:5173/
```

## 1. 系统组成

| 组件    | 技术                          | 默认端口 | 源码位置                            |
| ----- | --------------------------- | ---- | ------------------------------- |
| 门户前端  | Vue 3 + Vite + Element Plus | 5173 | `ruoyi-fastapi-frontend/`       |
| 门户后端  | Python FastAPI              | 9099 | `ruoyi-fastapi-backend/`        |
| 小智后端  | Python FastAPI              | 8000 | `xiaozhi-study/`                |
| 小智页面  | 原生 HTML/CSS/JavaScript      | 8000 | `xiaozhi-study/static/`         |
| 门户数据库 | MySQL                       | 3306 | 本机 MySQL 服务                     |
| 小智数据库 | 项目内便携 MySQL                 | 3307 | `xiaozhi-study/.runtime/mysql/` |
| 缓存    | Redis                       | 6379 | Docker `binhua-redis`           |
| 消息队列  | RabbitMQ                    | 5672 | Docker `binhua-rabbitmq`        |

小智页面保留原生前端，通过 iframe 嵌入门户。门户、小智和两套后端源码已经统一到一个 Git 仓库，<mark>不再维护单独的 overlay 补丁副本</mark>。

常用访问地址：

- 系统入口：`http://localhost:5173/`
- 门户后端接口文档：`http://127.0.0.1:9099/docs`
- 小智服务：`http://127.0.0.1:8000/`
- RabbitMQ 管理页：`http://localhost:15672`

默认登录账号为 `admin`，默认密码为 `admin123`。部署到其他环境后应立即修改。

## 2. 日常启动

### 2.1 启动依赖服务

在管理员 PowerShell 或已启动的 Docker Desktop 中执行：

```powershell
Start-Service mysql
docker start binhua-redis binhua-rabbitmq
```

如果 MySQL 服务名不是 `mysql`，先查看并启动实际服务：

```powershell
Get-Service | Where-Object { $_.Name -like "mysql*" }
```

### 2.2 启动完整系统

双击：

```text
Vibration-Image-Emotion-Analysis-main\start-local.cmd
```

脚本会依次启动：

1. 小智便携 MySQL：3307
2. 门户后端：9099
3. 小智后端：8000
4. Vue 前端：5173

脚本会等待后端 HTTP 接口就绪后再启动前端。模型首次加载或数据库初始化可能需要 10～30 秒。

<mark>不要同时运行</mark> `xiaozhi-study\start.cmd`，否则可能启动第二套小智服务。

### 2.3 打开系统

浏览器访问：

```text
http://localhost:5173/
```

如果曾关闭或重启过后端，使用 `Ctrl + F5` 强制刷新页面。

### 2.4 关闭系统

下面的命令只停止当前项目的 `5173`、`9099`、`8000`、`3307` 相关进程，不关闭系统 MySQL `3306` 和 Docker Redis/RabbitMQ：

```powershell
cd "E:\Learning\Binhua\Vibration-Image-Emotion-Analysis-main"

$project = (Resolve-Path ".").Path
$ports = 5173, 9099, 8000, 3307

$targets = @(
    (Get-NetTCPConnection -State Listen -ErrorAction SilentlyContinue |
        Where-Object { $_.LocalPort -in $ports } |
        Select-Object -ExpandProperty OwningProcess)
)

$targets += Get-CimInstance Win32_Process |
    Where-Object {
        $_.ExecutablePath -and
        $_.ExecutablePath.StartsWith(
            $project + "\",
            [StringComparison]::OrdinalIgnoreCase
        )
    } |
    Select-Object -ExpandProperty ProcessId

$targets |
    Where-Object { $_ -and $_ -ne $PID } |
    Sort-Object -Unique |
    ForEach-Object {
        Stop-Process -Id $_ -Force -ErrorAction SilentlyContinue
    }
```

如果还要关闭数据库和中间件：

```powershell
docker stop binhua-redis binhua-rabbitmq
Stop-Service mysql
```

## 3. 首次安装

### 3.1 基础环境

需要准备：

- MySQL 8
- Docker Desktop
- Node.js 和 npm
- Python 3.12
- FFmpeg
- 可用的摄像头

本项目当前示例路径：

```text
项目根目录：E:\Learning\Binhua\Vibration-Image-Emotion-Analysis-main
MySQL 客户端：D:\AA_install\mysql-8.0.44-winx64\bin\mysql.exe

```

项目路径建议使用全英文且不含空格的目录，避免 MediaPipe 和模型库加载失败。

### 3.2 后端开发配置

编辑：

```text

```

至少确认以下配置：

```env
APP_ROOT_PATH='/dev-api'
APP_HOST='127.0.0.1'
APP_PORT=9099

DB_TYPE='mysql'
DB_HOST='127.0.0.1'
DB_PORT=3306
DB_USERNAME='root'
DB_PASSWORD='your-mysql-password'
DB_DATABASE='ruoyi_fastapi'

REDIS_HOST='127.0.0.1'
REDIS_PORT=6379
REDIS_DATABASE=3

RABBITMQ_HOST='127.0.0.1'
RABBITMQ_PORT=5672
RABBITMQ_USERNAME='guest'
RABBITMQ_PASSWORD='guest'
RABBITMQ_VHOST='/'
```

可选配置：

```env
# AI Agent，不配置时仅影响 AI 对话
DASHSCOPE_API_KEY='your-dashscope-key'

# 本机摄像头索引，默认0

# 海康等 RTSP 摄像头

```

`.env.dev`、邮箱授权码、API Key、单点登录密钥和摄像头桥接密钥都属于本机私密配置，不应提交到 Git。

### 3.3 初始化门户数据库

以下命令会删除并重建 `ruoyi_fastapi`。已有业务数据时不要执行。

```powershell
$mysql = "D:\AA_install\mysql-8.0.44-winx64\bin\mysql.exe"
$project = "E:\Learning\Binhua\Vibration-Image-Emotion-Analysis-main"

& $mysql -h 127.0.0.1 -P 3306 -u root -p `
  --default-character-set=utf8mb4 `
  -e "DROP DATABASE IF EXISTS ruoyi_fastapi; CREATE DATABASE ruoyi_fastapi DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

& $mysql -h 127.0.0.1 -P 3306 -u root -p `
  --default-character-set=utf8mb4 `
  ruoyi_fastapi `
  -e "source $project/ruoyi-fastapi-backend/sql/ruoyi-fastapi.sql"
```

`--default-character-set=utf8mb4` 必须保留，否则 SQL 和页面中文可能乱码。

验证中文：

```powershell
& $mysql -h 127.0.0.1 -P 3306 -u root -p `
  --default-character-set=utf8mb4 `
  ruoyi_fastapi `
  -e "SELECT user_name, nick_name FROM sys_user LIMIT 5;"
```

初始化 SQL 只需导入一次。后端首次启动时还会通过 SQLAlchemy 自动创建缺少的业务表，例如：

- `binhua_analysis`
- `xuzhou_people_face`
- `xuzhou_people_group`
- `xuzhou_agent_message`
- `xuzhou_video`
- `xuzhou_scene`
- `xuzhou_alg`
- `xuzhou_alarm`

## 5. 摄像头和数据监控

数据监控支持三种来源：

- 小智摄像头
- 本机摄像头
- 海康 RTSP 摄像头

本机摄像头默认使用索引 `0`。如果电脑有多个摄像头，使用 FFmpeg 查看设备：

```powershell
& "D:\AA_install\EV\EVCapture\ffmpeg.exe" `
  -hide_banner -list_devices true -f dshow -i dummy
```

如果默认设备不是需要的摄像头，在 `.env.dev` 中调整：

```env
LOCAL_CAMERA_INDEX=0
```

修改后需要重启门户后端。

切换到小智摄像头后，前端会断开旧 MJPEG 视频流，后端会关闭本机摄像头采集线程。若摄像头指示灯仍亮，检查：

- 是否同时打开多个监控标签页
- vivo 办公套件、会议软件或相机应用是否占用摄像头
- 页面是否已经 `Ctrl + F5`

实时监测的数据链路：

```text
摄像头帧
├─ OpenCV SSD 人脸检测
│  └─ 人脸稳定门控
│     └─ PP-YOLOE_plus-S_face 检测
│        └─ ResNet50_face 特征提取
│           └─ 与已登记人员特征做余弦相似度匹配
└─ VibraimageCore
   └─ 帧差、ROI 振幅、Welch 频谱和统计公式
      └─ e1-e14、幸福指数和预警结果
```

模型说明：

- `PP-YOLOE_plus-S_face` 和 `ResNet50_face` 是 PaddleX 官方预训练模型。
- 人脸特征保存在数据库表 `xuzhou_people_face`。
- 实时视频识别阈值约为 `0.4`，人员匹配默认限定第 1 组。
- `e1-e14` 是振动图像统计公式的结果，不是神经网络输出。
- 当前仓库没有现场训练的人脸、情绪或声纹模型。
- 多模态 AI 助手使用远程 `qwen3-omni-flash`，只负责对话，不参与人脸识别或 e1-e14 计算。

模型缓存默认位于：

```text
.runtime\paddlex\official_models
```

通过其他方式直接运行 `app.py` 时，缓存可能位于用户目录：

```text
C:\Users\<用户名>\.paddlex\official_models
```

模型权重体积较大，保存在本机或发布包中，不提交 Git。

## 6. 常见问题

### 6.1 打开后显示 404

只能从门户首页进入：

```text
http://localhost:5173/
```

以下地址返回 404 是正常的，它们不是网页入口：

```text
http://localhost:5173/dev-api/
http://127.0.0.1:9099/
```

### 6.2 小智页面显示 503

通常是 `8000` 未启动，或者小智运行时缺少 `.runtime`、`.venv`。

```powershell
Get-NetTCPConnection -State Listen -LocalPort 8000
Get-Content ".runtime\logs\xiaozhi.err.log" -Tail 100
```

重新运行根目录 `start-local.cmd`，不要只启动门户。

### 6.3 接口出现 Axios 10 秒超时

先强制刷新页面。启动脚本现在会等待 `9099` 和 `8000` HTTP 就绪后再启动前端，设备列表查询也已单独设置为 20 秒并避免请求重叠。

如果持续超时，检查：

```powershell
Invoke-WebRequest http://127.0.0.1:9099/openapi.json
Invoke-WebRequest http://127.0.0.1:8000/
```

同时查看：

```text
.runtime\logs\backend.err.log
.runtime\logs\xiaozhi.err.log
.runtime\logs\frontend.err.log
```

### 6.4 本机摄像头没有画面

检查设备是否被其他程序占用，并确认索引正确：

```powershell
Get-PnpDevice -Class Camera -PresentOnly
```

如果笔记本摄像头和手机办公套件同时存在，`0` 通常是笔记本摄像头，`1` 可能是手机或虚拟摄像头。

### 6.5 MySQL Access denied

检查 `.env.dev` 中的 `DB_USERNAME`、`DB_PASSWORD` 和 `DB_DATABASE`。确保 MySQL Windows 服务正在运行：

```powershell
Get-Service mysql
```

### 6.6 中文乱码

数据库和表必须使用 `utf8mb4`。重新导入时必须包含：

```text
--default-character-set=utf8mb4
```

### 6.7 Redis 或 RabbitMQ 无法连接

```powershell
docker ps
docker exec binhua-redis redis-cli ping
docker exec binhua-rabbitmq rabbitmq-diagnostics -q ping
```

确认 `.env.dev` 使用：

```text
Redis: 127.0.0.1:6379
RabbitMQ: 127.0.0.1:5672
```

### 6.8 人员信息上传失败

`xuzhou_people_face.group_id` 指向 `xuzhou_people_group.id`。实时识别默认使用第 1 组，缺少分组时先创建：

```powershell
$mysql = "D:\AA_install\mysql-8.0.44-winx64\bin\mysql.exe"

& $mysql -h 127.0.0.1 -P 3306 -u root -p `
  --default-character-set=utf8mb4 `
  ruoyi_fastapi `
  -e "INSERT INTO xuzhou_people_group (id, name, created_time, updated_time, is_deleted) SELECT 1, '默认分组', NOW(), NOW(), 0 WHERE NOT EXISTS (SELECT 1 FROM xuzhou_people_group WHERE id = 1);"
```

其他常见原因包括照片中没有清晰人脸、文件不是 JPG/PNG，或 PaddleX 模型首次加载失败。

### 6.9 AI Agent 无法回答

确认 `.env.dev` 中的 `DASHSCOPE_API_KEY` 有效，并检查服务器能否访问阿里云百炼。

### 6.10 模型依赖安装失败

使用项目指定的 Python 3.12，检查磁盘空间和网络。默认使用 CPU 版 PaddlePaddle；没有 GPU 环境时不要安装 CUDA 版依赖。
