# 视频与行为识别更新

本次直接修改原桌面项目，无需迁移账户或学习记录。

## 视频

USB 采集与上传分离，最多一个上传请求，不排队积压旧画面。默认取景间隔从 125ms 改为 60ms，根据相机实际速度运行，并非保证固定帧率。浏览器仍只显示最新真实 JPEG；后台每 2 秒处理一个候选画面，分析与预览互不等待。

修复 Windows 状态文件临时锁定导致的 3 秒摄像头断连；状态心跳降为每秒一次，减少磁盘和日志开销。短暂锁定只跳过本次状态保存，不重连设备。

## 识别

纠正 Ultralytics YOLOv8 ONNX 已解码坐标的二次解码问题，以及 OpenCV NMS 使用 xywh 的参数格式。统一采用 ONNX Runtime CPU 推理，避免安装环境不同导致两条推理路径行为不一致。

新增模型原本支持的举手、站立和讨论。举手及讨论计入投入样本，站立单独记录，不自动算分心。模型置信度至少 0.6，候选类别得分差至少 0.1；连续 3 次且跨度至少 2 秒才确认新状态。手腕位置和低头本身不再自动当作书写或阅读，未确认时不把原始动作作为已确认行为展示。

保留实物手机和手部关联，图像与分析结果按 frame_id 对齐，不能把历史手机告警归到当前照片。

## 使用体验

新增持续肩部倾斜的坐姿提示、当前取景质量建议、连续投入计时和 45 分钟休息建议。离座、状态中断或摄像头间隔超过 4 秒时重置投入计时，不把断线时间算作学习。

删除登录页“本机运行 · 使用原项目账户登录”及监测页重复的技术说明，保留操作提示、故障提示和删除确认。刷新页面即可加载新的前端资源。

这些更新没有重新训练模型。举手、站立、讨论及阅读/书写等类别仍需用实际使用场景评估准确率；坐姿和取景建议是画面几何及质量规则，不是医疗评估或情绪识别。

## 实测记录

本机当前设备 USB 5B14267334，旧 125ms 串行流程实测 7.91fps；修复后的第一轮实时流实测 14.19fps。结果随灯光、USB、电脑负载及设备变化，详细记录见 .runtime/video-baseline-20261011.json 和 .runtime/video-after-20261011.json。

较长验证：连续 180 帧实际预览 13.08fps，后台完成 8 次分析，状态接口 109ms，精确分析截图返回 200；未授权视频请求返回 403。34 项 Python 回归和视频、交互 JavaScript 回归通过。短时间样本不能代表所有设备或长时稳定性，也不等于模型准确率验证。
