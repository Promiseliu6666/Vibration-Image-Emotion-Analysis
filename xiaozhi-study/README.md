# 小智伴学

面向学习过程的行为观察、用眼休息与坐姿习惯回顾系统。当前版本更新于 2026-10-15，直接对应桌面运行的原项目。

## 当前功能

- 实时监测：原始 JPEG 预览、对应分析画面对照、设备状态与独立的预览/监测控制。
- 事件闭环：持续行为确认、常驻提醒、小智语音、事件截图留存和人工识别核对。
- 健康记录：用眼、久坐与体态、疲劳与节律、活动回看；日期与行为筛选、继续加载更早记录。
- 数据分析：活动分布、每日变化、阶段对比、周/月报告、PDF 与 CSV 导出。
- 日常行动：劳逸结合观察时段、学习待办、结合近期摘要问答的小智助手。
- 设置：USB 物理身份与接入验证、兼容固件 Wi-Fi 配置、共享查看账号及照片留存。

本轮优化与测试详见 [2026-10-15 更新说明](docs/optimization-20261015.md)。

## 本仓库内容

包含Python后端、网页资源、识别模型、依赖清单、测试及说明。不包含API密钥、用户数据库、学习图片、日志、虚拟环境或设备私人备份。此仓库为源码，不是包含Python/MySQL的一键运行包。

## 部署准备

使用Python 3.11、MySQL及全英文项目路径。依据requirements-compatible.txt安装依赖，根据config.py与.env.example配置自己的数据库和可选AI服务；数据库结构与初始化入口见init_db.py。启动服务入口为main.py。start.cmd等便携启动脚本依赖单独准备的.runtime与.venv，不会随Git下载自动获得完整运行环境。

原桌面已有环境可以继续使用；请勿把本仓库的示例配置覆盖到正在使用的个人配置中。

## 局域网和 Wi-Fi

项目适合家庭或少量用户的校园局域网，支持账户角色、局域网监听配置及带设备密钥的网络图像上传。校园网可能隔离设备，必要时使用共同热点或家庭路由器。

当前已验证的 Watcher 接入方式是 USB。小智连上 Wi-Fi 不等于自动把摄像头画面上传到本项目；网络采集端必须实现现有认证上传协议。network_client.py 是网络上传参考端。当前 Wi-Fi 图像上传本身也不提供小智语音下发能力。完整无线摄像头+语音链路不能仅靠配置地址实现，仍需适配设备端协议。请勿将局域网服务直接暴露至公网。

学习助手可选配置 .env 的模型服务信息；发布包仅提供 .env.example，无个人密钥。启用外部模型后，行为摘要/对话可能发送到配置的服务，图片识别仍在本地进行。

## 目录结构与源码入口

服务端代码按职责分包到 app/ 下，根目录只保留启动入口与启动脚本：

- main.py：服务入口，实现在 app/server.py
- app/core/：配置、数据库、统一路径（paths.py）、账户与设备鉴权
- app/device/：USB 物理身份识别与采集进程控制
- app/api/：HTTP / WebSocket 接口层（路由与推送）
- app/analysis/：识别流水线（分析、连续性判定、困难度、语音提醒）
- watcher_usb.py：本机 USB 摄像头采集客户端，独立进程运行
- tools/：辅助脚本（数据库初始化、无线配网、说明书生成、网络参考端）
- static/、models/、tests/：网页资源、识别模型、回归测试

运行时路径统一由 app/core/paths.py 提供，不再用 __file__ 猜测层级，文件在包内移动不会改坏路径。static/dashboard.html、console.js、console.css、workspace.js 为当前界面；session.html 仍由事件详情使用，并非旧版废页，因此保留。

tests 保留必要回归测试。requirements-compatible.txt 与 requirements-lock.txt 记录现用依赖。模型许可见 models 内说明；固件许可见固件包 LICENSE，随包组件保留各自许可。

## 固件构建与烧录

仅适配 SenseCAP Watcher ESP32-S3、32MB 闪存及包内分区布局。其他型号不能使用这些二进制。此包以官方小智 v2.2.6 为基础，构建工具版本 ESP-IDF 5.5.5。烧录工具依赖见 firmware/requirements-flash.txt；完整编译工具链未装入源码包，需要另装 ESP-IDF 5.5.5。

在 ESP-IDF PowerShell 环境进入 source，执行 `idf.py -DSDKCONFIG=sdkconfig.voice set-target esp32s3`，再执行 `idf.py -DSDKCONFIG=sdkconfig.voice build`。源码含 managed_components 与依赖锁；工具链首次配置或补齐依赖可能需要网络。修改后重新生成的二进制应建立新的校验信息，不能拿旧校验清单冒充新构建。

firmware/flash_device.py 提供 backup 和 flash 两个子命令。先停止 USB 采集、关闭串口终端，再按固件包 README 的步骤备份。脚本记录 USB 序列号、芯片 MAC 和整机 SHA256；flash 核对相同物理芯片、32MB 备份、分区布局及已编译文件校验后，只更新 app 与语音模型，不写 NVS、分区表或摄像头协处理器。

本地中文提醒音频在 main/phone_reminder.ogg（用眼为 eye_reminder.ogg），Watcher 板级代码注册了 `study_display`（四行显示）、`study_voice_play`（服务端到点播报）、`study_voice_test`（逐类测试），并保留`study_sync` / `study_state`兼容路径。定制固件按已批准设置暂缓自动 OTA，保留手动升级；后续更新需人工维护。刷回官方版本会丢失定制语音接口。

## 验证与限制

实时预览已用真实设备验证，未登录访问被拒绝，按分析帧编号取图成功。相关后端 25 项测试与 5 组界面回归通过。独立环境已从新的英文目录验证登录、空数据库及包内 Python 运行时。压缩包将进行 CRC 完整性校验，并检查不包含私密运行数据。界面验证包含自动回归，未完成新电脑实际硬件兼容性测试。

此包不包含历史学习数据，也不承诺高帧率高清视频。项目仍需要真实使用场景的准确率评估；固件重新编译和新设备烧录需按对应硬件验证。

最新预览优化、测量数据与新操作见 docs/runtime.md。当前源码比此前交付压缩包更新。

## 久坐与用眼

独立入口已合并为「久坐与用眼」，把坐姿、连续在位与屏幕相关活动统一成周 / 月报告；已评估样本不足时不给出结论，样本占比不等于全天时长。

- 用眼提醒只由小智语音播放；默认连续近距离用眼每 20 分钟一次，可在设置页按当前设备调整重复间隔，设备端需烧录含 `eye_reminder.ogg` 的固件。
- 坐姿倾斜、趴桌、疲劳和其他提醒均由服务端按用户设置节流；固件不再执行提醒冷却或优先级。
- 设置页可按当前设备统一关闭自动语音，也可分别开关手机、用眼、坐姿、趴桌、久坐、疲劳、视线离开和画面质量提醒，并为每类设置首次提醒前的持续时长和之后的重复间隔；本人可在页面上反馈「已休息 / 稍后」。
- 后端模块：app/api/health_api.py（偏好与自报反馈）、app/api/wellbeing_reports.py（周 / 月报告）、app/analysis/eye_alerts.py（用眼语音提醒）。

测试所用真人照片不上传；依赖真人照片的测试会跳过，需自行准备经授权的本地测试图片。上述结果来自原桌面运行环境的本地验证。
