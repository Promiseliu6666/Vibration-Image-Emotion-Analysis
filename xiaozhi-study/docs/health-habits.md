# 学习健康陪伴（2026-10-12）

定位为学习空间中的健康习惯陪伴，不是临床医疗或心理诊断。

实时页增加劳逸结合卡片，观察连续在位的采样片段。它不依赖“已识别学习活动”，因此未知活动也可触发休息提示；离开、断线及大采样间隔会重新累计。不声称这段时间一直久坐、看屏幕或专注。

个人账户可设置 15–90 分钟时段监测间隔，关闭休息或姿态提示。姿态需连续有效关键点证据；镜头倾斜也会影响结果，因此建议先检查取景。

用户可选择“我已休息活动”“我已检查调整”或“10 分钟后提醒”。反馈记录保存在 health_actions，并按登录账户和设备查询。它是用户自报，不能证明姿势正确、休息时长或健康改善。月报只汇总本人自报的休息次数。

提醒偏好由 health_preferences 持久保存；暂缓状态由账户与设备区分，保存在当前浏览器。换浏览器时不会同步暂缓状态。

AI 助手沿用既有文字行为摘要，不上传原始图像给 DeepSeek；提示词明确非医疗边界及样本占比的局限。调用仍需有效 API 密钥和余额。

这些功能对应赛道中的日常预防关怀、连续观察、习惯管理和隐私友好设计。目前不具备远程问诊、慢病诊疗或老年康养专用能力。
