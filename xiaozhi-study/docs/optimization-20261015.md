# 2026-10-15 整体优化

本轮同时更新桌面运行项目与 Gitee 源码，沿用顶部导航、日光书桌风格以及现有功能。未变更个人配置、设备固件、数据库内容或图像分辨率。

## 监测与事件

- 视频旁增加画面时间、分析依据时间和差值，支持直接切换至当前判断使用的截图。
- 当前状态提前到侧栏首位，观察时段放在其后，先看清结果再进行操作。
- 预览保留完整原图；比例不一致时以同一画面的柔化背景衔接，避免大块浅色空白。
- 使用手机的常驻提醒增加相关记录入口，并定位提醒当天的数据；新提醒携带时段编号时可直接回看证据。
- 图像缓冲有明确上限，异常流会重新连接；解码持续慢于来帧时仍定期显示画面，避免一直丢帧而无法显示。
- 统一采集时间口径；只有时间戳一致才显示为同一帧，不再因整数秒取整把两帧混为一谈。

## 数据查询与交互

- 今天、近七天、指定日期由后端直接限定候选时段，再进行汇总。时间范围统一采用中国日历的 UTC+8 边界。
- 首次读取 50 段，按需继续加载至 500 段；页面与导出明确显示实际载入范围，完整明细仍可按日期导出。
- 自动刷新在数据未变化时保留原有内容；发生更新时恢复普通短记录的展开状态，操作列表控件时暂缓自动重绘。
- 切换设备立即清除旧统计，取消旧请求；旧设备的迟到响应不能覆盖新设备页面。自动选择替代设备同样执行清理。
- 浏览器前进、后退与顶部导航一致，切换页面保留各自滚动位置。

## 运行与维护

- 照片保留策略维护移至独立任务，启动延后执行，不再阻塞实时分析器，避免启动时连续执行两次清理。
- 查询先限定目标时段集合，再关联分析样本，避免为显示最近少量记录先汇总整库。
- 设置分区增加快捷入口，保留原有折叠；照片试算等设置数据先读取保存值，并忽略过时的异步试算结果。
- 设备卡片及时更新画面与分析时间；测试设备显示开关、在线数量与实际筛选一致。
- 移除未加载的旧侧栏样式，日期命名的融合样式归入 workspace-refinements.css，补充职责说明。
- 保留上一版本本地已有的跨设备休息反馈隔离与关闭时设备屏幕任务回收修复。

## 验证

在原桌面环境执行后端回归：138 项通过，2 项因管理员默认密码已更改而跳过。前端 5 组回归覆盖统计、时区边界、跨设备异步反馈、视频分包解析、请求竞争与增量加载；全部 JavaScript 语法检查通过。

本机实际数据查询记录：最近 50 段约 154 ms、今天 16 段约 40 ms、近七天 50 段约 107 ms、读取 100 段约 214 ms。耗时受硬件、数据量和并发影响，以上为本轮实测，不代表各电脑固定表现。

浏览器验证涵盖顶部导航、返回操作、设备切换、空日期、100 段加载、设置试算与视频/分析对应画面。应用后端已重启；设备采集客户端与数据库继续沿用原有环境。

本轮未更换识别模型，也未通过降低清晰度换取帧率。物理 USB 链路的速度仍取决于原始图像大小、设备协议和采集耗时；本轮改进的是预览与分析之间的调度、显示及状态一致性。
