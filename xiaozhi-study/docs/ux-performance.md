# 操作与响应优化

状态与图片分别更新：实时页约1秒刷新，其他页面约4秒刷新；隐藏窗口不继续请求。请求失败逐步降低重试频率，避免重复错误提示。每日摘要仅在实时页每30秒更新。

同一个frame_id只下载一次；新图像解码完成后才替换旧图。切换设备、隐藏画面、进入其他页面会取消旧请求，并释放不用的图片资源。仍按真实frame_id绑定分析截图，同步中明确提示当前仍是上一帧。预览显示/隐藏选择保存在浏览器。

已经识别过的同一物理USB设备可直接恢复采集。按钮等待过程中不会重复启动；后端核对USB序列号，发现换设备时要求重新检测。语音控制继续使用真实硬件检查，不依赖界面缓存。

状态页USB健康检查缓存最长2秒，开始/停止后立即失效。分析模型CPU线程限制为2，并关闭空闲自旋，减少对电脑其他操作的资源竞争；检测阈值、时序确认和语音防抖规则保持。

界面收紧欢迎区、放大常用操作按钮，增加连接状态、立即更新、个人眼部标定进度；语音测试收纳到可展开区域，当前设备卡片有明确标识。

验证：新增UI回归覆盖重复图像、解码后替换、切换/隐藏取消、资源释放、后台停止刷新、同一物理设备恢复及重复点击保护。后台UI缓存与物理设备变化拒绝、原语音回归通过。实际暂停/恢复和新图像接口通过。记录位于 .runtime/ux-controls-verification.json 和 .runtime/ux-performance-verification.json。

重复状态请求实测中位数从77.1ms至29.3ms，仅为本机该次测量，非所有页面或所有电脑性能保证。设备采样仍约每秒一帧，预览不是高帧率视频。

连续实时预览已上线：当前预览约 2 帧/秒，独立于分析。保留对选取画面进行分析模式；详见 live-preview.md。
