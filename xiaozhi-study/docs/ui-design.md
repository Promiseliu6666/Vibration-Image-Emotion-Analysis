目标用户：查看孩子学习状态的家长，以及希望理解并调整自身学习过程的大学生、研究生。无需身份模式，也不增加人群专属功能。

内容特点：真实视频持续更新，行为识别可能暂时无法确认，历史数据是采样记录而非绝对学习时长。保留相关语义与现有功能。

设计计划：白色 #FFFEF9 的画面底板，背景 #F8F9F3，鼠尾草绿 #476953 用于可操作与已连接状态，杏色 #F1E3CE 用于计时，浅绿 #EDF2E3 用于已保存的学习记录，文字 #353D38。标题采用 STSong / SimSun，表达学习手账的书卷感；按钮、正文使用 Microsoft YaHei UI，保证操作可读性；计时与统计数字采用 Georgia 并保持原有等宽数字设置。

设计审阅：取消侧栏以扩大视频区域，不使用无关大屏数字、序号、英文装饰文字与漂浮徽章。视频采用画框层次，识别区开放融入页面，计时与历史汇总使用不同材质色块。导航与已有设备数据保持一个来源。摄像头图标只用于说明画面关联的状态，去除会被误认为复选框的空框装饰。
