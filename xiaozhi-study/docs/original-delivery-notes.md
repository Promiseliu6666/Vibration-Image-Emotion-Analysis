## 项目运行

适用 Windows 64 位。把项目包解压至可写、全英文路径，例如 C:\Xiaozhi\xiaozhi-study。压缩包内文件夹为 xiaozhi-study；识别库无法从含中文的路径加载模型，请勿把项目放在中文目录下；首次运行需要约数分钟初始化数据库。双击 start.cmd 启动服务，再双击 open-project.cmd 打开 http://127.0.0.1:8000。启动服务不自动打开新标签页，重启后可以刷新原页面。

新安装默认管理员为 admin / admin123，首次使用请在系统设置修改密码。每个新安装生成独立的数据库密码和登录密钥。数据库优先使用 3307，若被占用则自动选择其他端口；配置保存在 .runtime/runtime.json。默认本机访问，局域网开放前必须修改默认密码。与原桌面项目同时运行时，应用端口 8000 仍会冲突，应先关闭另一份服务。

双击 start-watcher.cmd 启动 USB 摄像头采集。设备管理中添加/检测并核对真实画面，系统按物理 USB 序列号区分设备，不能把不同设备归并为同一设备。多设备时请在界面选择端口。停止采集用 stop-watcher.cmd；停止项目和数据库用 stop.cmd。当前桌面项目保留已有配置与历史，不会执行新安装初始化。

运行环境已随项目包提供，不要求在新电脑预先安装 Python 或 MySQL。虚拟环境由准备脚本在解压后重新定位。USB 端口识别还依赖电脑能识别设备的 CH342 驱动；如设备不出现，请安装厂商对应驱动。其他操作系统不支持此 Windows 环境包。

## 功能与数据流程

学习空间支持连续实时预览和对选取画面进行分析两种模式。当前高清 640×480 模式约 3 FPS；240×240 流畅模式此前约 8–13 FPS，详情见 docs/runtime.md。后台约每 2 秒分析一张，预览保留原 JPEG 不再二次压缩。画面时间与分析时间分开显示；事件保留准确帧编号和对应证据，避免图片与描述错配。当前没有完整录像保存功能。

手机判断需检测到手机实物并与可见手部位置对应，再结合连续画面确认；姿势本身不直接认定玩手机。疲劳判断先积累 60 个有效人脸样本标定，无人画面不沿用旧疲劳值。识别用于辅助提醒，小手机、遮挡、背光、模糊仍可能漏检。保持镜头稳定并看清脸、手和桌面；延长取帧间隔不能改变曝光。

USB 链路：Watcher 摄像头 → watcher_usb.py → 认证上传接口 → 最新帧队列 → analyzer.py 与连续证据 → MySQL → 界面/事件 → phone_alerts.py → 同一物理设备的 ESP32 语音串口。

玩手机提醒同时显示在系统界面并由小智播放本地中文语音。行为确认及播报采用防抖与冷却，设备正在对话时暂缓；播放失败会如实显示。管理员可以使用「测试小智语音」核对扬声器，测试不写假的手机事件。

## 局域网和 Wi-Fi

项目适合家庭或少量用户的校园局域网，支持账户角色、局域网监听配置及带设备密钥的网络图像上传。校园网可能隔离设备，必要时使用共同热点或家庭路由器。

当前已验证的 Watcher 接入方式是 USB。小智连上 Wi-Fi 不等于自动把摄像头画面上传到本项目；网络采集端必须实现现有认证上传协议。network_client.py 是网络上传参考端。当前 Wi-Fi 图像上传本身也不提供小智语音下发能力。完整无线摄像头+语音链路不能仅靠配置地址实现，仍需适配设备端协议。请勿将局域网服务直接暴露至公网。

学习助手可选配置 .env 的模型服务信息；发布包仅提供 .env.example，无个人密钥。启用外部模型后，行为摘要/对话可能发送到配置的服务，图片识别仍在本地进行。

## 源码入口

main.py 为服务入口；analyzer.py、phone_detector.py、temporal_analysis.py 为识别及连续判定；watcher_usb.py / usb_identity.py 负责 USB 与物理身份；continuous_preview.py 与 static/live-preview.js 为连续预览；phone_alerts.py 为语音路由与规则；access_control.py 为账户与设备鉴权；static/dashboard.html、console.js、console.css、workspace.js 为当前界面。session.html 仍由事件详情使用，并非旧版废页，因此保留。

tests 保留必要回归测试。requirements-compatible.txt 与 requirements-lock.txt 记录现用依赖。模型许可见 models 内说明；固件许可见固件包 LICENSE，随包组件保留各自许可。

## 固件构建与烧录

仅适配 SenseCAP Watcher ESP32-S3、32MB 闪存及包内分区布局。其他型号不能使用这些二进制。此包以官方小智 v2.2.6 为基础，构建工具版本 ESP-IDF 5.5.5。烧录工具依赖见 firmware/requirements-flash.txt；完整编译工具链未装入源码包，需要另装 ESP-IDF 5.5.5。

在 ESP-IDF PowerShell 环境进入 source，执行 `idf.py -DSDKCONFIG=sdkconfig.voice set-target esp32s3`，再执行 `idf.py -DSDKCONFIG=sdkconfig.voice build`。源码含 managed_components 与依赖锁；工具链首次配置或补齐依赖可能需要网络。修改后重新生成的二进制应建立新的校验信息，不能拿旧校验清单冒充新构建。

firmware/flash_device.py 提供 backup 和 flash 两个子命令。先停止 USB 采集、关闭串口终端，再按固件包 README 的步骤备份。脚本记录 USB 序列号、芯片 MAC 和整机 SHA256；flash 核对相同物理芯片、32MB 备份、分区布局及已编译文件校验后，只更新 app 与语音模型，不写 NVS、分区表或摄像头协处理器。

本地中文提醒音频在 main/phone_reminder.ogg，命令 study_phone_alert 在 Watcher 板级代码注册。定制固件按已批准设置暂缓自动 OTA，保留手动升级；后续更新需人工维护。刷回官方版本会丢失定制语音接口。

## 验证与限制

实时预览已用真实设备验证，未登录访问被拒绝，按分析帧编号取图成功。相关后端 25 项测试与 5 组界面回归通过。独立环境已从新的英文目录验证登录、空数据库及包内 Python 运行时。压缩包将进行 CRC 完整性校验，并检查不包含私密运行数据。界面验证包含自动回归，未完成新电脑实际硬件兼容性测试。

此包不包含历史学习数据，也不承诺高帧率高清视频。项目仍需要真实使用场景的准确率评估；固件重新编译和新设备烧录需按对应硬件验证。

最新预览优化、测量数据与新操作见 docs/runtime.md。当前源码比此前交付压缩包更新。
