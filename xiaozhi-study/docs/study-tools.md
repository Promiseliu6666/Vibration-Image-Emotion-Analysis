# 识别与纠正

> 本文件原为"学习计划与识别核对"。学习计时、每日目标与待办清单已于 2026-10-14 撤除（属学习效率工具，不产出健康数据），下面只保留与健康识别质量相关的说明。

## 识别变更

不再把仅仅朝向摄像头自动当作投入看屏幕。具体动作证据不足时记录为观察中。复用物体检测模型，增加书本、电脑及键盘证据：手部与书本交互且视线朝下可作为阅读辅助，手部与键盘交互可作为电脑操作辅助，单独看见书或电脑不足以判断正在学习。物体类别依照 TensorFlow 官方 COCO 标签表： https://github.com/tensorflow/models/blob/master/research/object_detection/data/mscoco_label_map.pbtxt 。

继续使用当前动作模型的举手、站立、讨论、阅读、书写、听讲等类别及连续画面确认。没有发生的类别不生成假样本。界面提供可支持行为列表，以及当前判定的证据来源。

平均疲劳只统计面部可见且已完成基线适应的样本，没有有效疲劳样本显示空值，不用 0 代表正常。

## 纠正误判

点击核对这张分析图，窗口冻结对应 frame_id 的原始图与模型结果，最长保留 10 分钟，避免新画面覆盖原图。纠正记录保存模型原判断、人工标签、补充说明、证据及图像摘要，不覆盖历史分析。不勾选另存图片时不额外留存照片；勾选后在本机保存，并随图片保留期清理。

这些纠正不会立即训练模型或让准确率自动提升。可作为后续真实场景评估和训练资料。原有旧记录保留，因此更新前的统计不会被重新计算成新的行为。

数据表只保留 `study_feedback`（纠正记录按账号隔离）；原 `study_profiles`、`study_tasks`、`study_timers` 已不再创建。
