# 连续实时预览

原桌面项目现在支持两种画面模式：

- 实时视频预览：持续显示小智传回的原始 JPEG 画面，画面更新独立于后台分析。
- 对选取画面进行分析：显示当前分析结果所使用的准确截图，便于核对判断。

在「学习空间」画面下方选择模式。页面分别显示画面时间与分析时间，避免把最新画面误认为某条分析的依据。隐藏画面、切换设备、离开页面时会停止对应预览连接。

当前 USB 小智实测输出 640×480，每秒约 2 张画面。服务每隔约 2 秒抽取一张分析，并结合连续画面确认行为。预览保留设备原始 JPEG，不再缩小或再次压缩。慢速分析不会要求预览等待分析结果。预览需要登录，访问密钥不会放在图片网址中。

这是连续低帧率预览，尚未保存完整录像，也不是普通摄像头每秒 25/30 帧的视频。硬件输出自身已有较强压缩，软件无法恢复已经丢失的细节。保持设备稳定、镜头对准学习者并改善光线，有助于实际清晰度；延长采集间隔不等于延长曝光。目前未验证可用的曝光控制接口。

2026-10-10 验证：真实设备连续收到 8 张 640×480 画面，约 2.14 帧/秒；未登录访问被拒绝；按分析帧编号读取截图成功。实测数据在 `.runtime/live-preview-verification.json`。后台与 USB 采集已重启加载更新。
