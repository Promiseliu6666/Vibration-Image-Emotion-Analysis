# 连续画面分析与截图对应

已在原桌面项目实现本地连续取帧和每设备独立的短时间窗分析。USB 默认约每秒取一帧；实际速度取决于设备读取和分析耗时。

每台设备只保留最新等待分析帧；超过3秒的排队帧不参与分析。推理在后台线程执行，界面状态请求不会被推理阻塞。

手机使用：本地 SSD-MobileNetV1 检测到手机，置信度至少0.55，且与可见手腕/手指位置对应；至少3次连续画面、持续2秒才确认。之后原语音防抖继续要求4秒连续手机结果，避免偶尔拿起手机就播报。摸脸、扶眼镜或看天花板不再凭姿态判定玩手机。

疲劳：先积累60个有效人脸样本建立个人眼部基线，期间界面显示“标定中”，不产生疲劳告警。当前画面必须能看清人脸；无可见人脸不沿用旧疲劳值产生告警。低可见性关节点不作为趴桌或手部活动证据。断流超过4秒重新积累连续状态。

每次分析保存采集时间、独立frame_id、连续证据摘要和对应图像。实时界面显示与结果相同frame_id的截图；事件记录仍使用该帧自己的文件路径。旧历史没有新证据，不修改原数据，标记“旧版结果，未经新算法复核”。新增evidence_json字段可为空，原有数据兼容。

这不是高帧率视频：现有USB摄像头接口是采样图像，每秒取帧适合学习行为和提醒，不能可靠计算快速眨眼等细微运动。完整视频需要更高采集率和对应硬件通道；仅把单帧编码成视频不会修复误判。手机被遮挡、很小或背光仍可能漏检，请保持镜头朝向脸和双手，判断结果作为辅助提示。
