# 手机使用语音提醒

检测结果为“使用手机”且画面有人时，实时监测页面显示提醒卡片。持续至少 4 秒、累计至少 3 次连续识别后，后台向同一物理小智发送本地语音命令。超过 8 秒没有连续结果时重新确认；排队超过 8 秒的旧画面不触发语音；每台设备至少间隔 60 秒播报一次。

提醒内容：“检测到你正在使用手机，请放下手机，回到学习。”

语音由小智扬声器播放，音频在固件中，无需在线 TTS 服务。USB 摄像头与语音控制串口必须具有相同 USB 序列号；系统不会把一台设备的检测结果发送给另一台设备。设备正在对话时暂缓提醒，持续检测到手机使用时稍后重试。没有播放回执时，页面显示失败或不可用，不显示播报成功。

登录管理员，在实时监测页选择当前连接的物理设备，点击“测试小智语音”可验证扬声器。此测试不写入假的手机使用分析记录。

本固件按你的选择暂缓自动升级，保留手动升级；后续固件安全更新需手动安装，官方固件可能覆盖定制语音接口。设备原有网络配置保留。

目前实现 USB 语音通道。Wi-Fi 图像接入仍可显示告警；仅通过 Wi-Fi 上传图像不会自动获得本机 USB 语音能力。
