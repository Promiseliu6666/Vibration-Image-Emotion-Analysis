# 学习行为语音提醒

本轮接入手机、坐姿倾斜、趴桌、疲劳、视线离开、久坐、20-20-20 用眼和画面质量提醒。服务端统一负责持续时长、重复间隔、优先级和全局语音间隔；固件只更新屏幕、检查扬声器可用性、播放指定本地音频并返回回执。

检测结果为“使用手机”且画面有人时，实时监测页面显示提醒卡片。服务端累计连续判断并按用户设置的持续时长决定是否播报；手机显示标志用于网页和屏幕展示，不再触发固件侧的另一套冷却。

提醒内容：“检测到你正在使用手机，请放下手机，回到学习。”

语音由小智扬声器播放，音频在固件中，无需在线 TTS 服务。USB 摄像头与语音控制串口必须具有相同 USB 序列号；系统不会把一台设备的检测结果发送给另一台设备。设备正在对话时暂缓提醒，持续检测到手机使用时下一轮心跳重试。回执里 `voice=busy/muted` 时页面如实显示，不写成播报成功。

新固件使用 `study_display` 接收四个显示字段，使用 `study_voice_play <kind>` 播放一条已经由服务端判定到点的提醒。`study_voice_play` 不改变自动提醒状态；`played` 回执才让服务端启动重复间隔，`busy/muted/error` 会稍后重试。协议细节见固件目录的 README。

四种显示字段分别来自活动分类、连续近距离用眼秒数、连续在位秒数和风险标志位。黄色风险行使用同一份服务端风险判断；注意力、姿态、疲劳、画面质量和用眼达到门槛后都可以触发黄色提示，但黄色显示和语音播报是两个独立决策。

设置页的“提醒设置”卡按当前选择的物理设备保存，不要求管理员身份。用户可以统一关闭自动语音提醒，也可以分别关闭手机、连续用眼、坐姿、疑似趴桌、久坐、疲劳、视线离开和画面质量提醒，并为每类分别设置“首次提醒前持续多久”和“提醒后隔多久再次提醒”。这些时间完全由服务端执行；设置变更最多约 5 秒应用到实时分析。手动观察时段仍可单独启动并使用一次到点提醒。

登录用户可以在设置页选择当前连接的物理设备，并在每一类提醒后点击“测试”直接播放对应本地音频。测试仅在本机 USB 采集正在控制该设备时可用，不写入手机使用事件，也不会占用真实提醒的重复间隔。八类测试由固件的 `study_voice_test` 命令直接播放，不经过自动提醒判定。

本固件按你的选择暂缓自动升级，保留手动升级；后续固件安全更新需手动安装，官方固件可能覆盖定制语音接口。设备原有网络配置保留。

目前实现 USB 语音通道。Wi-Fi 图像接入仍可显示告警；仅通过 Wi-Fi 上传图像不会自动获得本机 USB 语音能力。
